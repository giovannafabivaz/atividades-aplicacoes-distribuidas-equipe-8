# Exercício Prático: Aplicativo Contador Avançado

Este projeto é um exercício prático focado na construção de um aplicativo de contador avançado utilizando React Native, Expo Router e Context API. Em vez de apenas somar e subtrair, a atividade foi pensada para explorar regras de negócio, navegação e manipulação de estado, sendo dividida nas seguintes fases de desenvolvimento:

Na primeira fase, de **Estruturação Base e Navegação**, configuramos o roteamento do aplicativo (baseado em arquivos com o Expo Router) e criamos o "cérebro" do app usando a Context API. Isso nos permitiu ter um estado global, fazendo com que o valor do contador pudesse ser acessado e atualizado de qualquer tela, sem perder a informação durante a navegação.

Em seguida, avançamos para a fase de **Operações e Validações Iniciais**. Nela, implementamos o botão de decremento com uma regra rígida: o contador nunca pode ficar com um valor negativo. Também criamos uma tela para o usuário definir um valor específico através de um campo de digitação. Para isso, foi necessário criar validações que impedem a entrada de letras (valores Not-a-Number) ou números menores que zero, garantindo a integridade do estado.

A terceira fase foi focada em **Lógica Avançada e Histórico**. Desenvolvemos uma tela exclusiva para cálculos, onde o usuário pode somar, subtrair, multiplicar ou dividir o valor atual do contador por um novo número. Essa etapa exigiu proteções adicionais, como bloquear tentativas de divisão por zero e arredondar valores quebrados. Junto a isso, implementamos um sistema de rastreamento de histórico usando um array no estado global. O aplicativo passou a salvar automaticamente cada alteração do contador, exibindo os últimos 10 valores em uma lista dinâmica (`FlatList`), com a opção de limpar esse registro.

Por fim, na fase de **Refinamento e Segurança**, adicionamos uma funcionalidade de "Reset" para zerar o contador. O objetivo aqui foi evitar cliques acidentais, implementando caixas de diálogo de confirmação. O desafio dessa etapa foi fazer isso de forma multiplataforma: usamos o padrão `window.confirm` quando o aplicativo roda no navegador (Web) e o `Alert.alert` nativo quando roda em dispositivos móveis.
